Retry Pressure
Agentic Systems Phenomena
Failure Modes · Alignment
When an agent optimizes for passing the exit check rather than solving the actual problem — because exiting the loop is the only reward signal available to it.

Real Example
snake_game · 2025

Agent shipped a snake game. Every test passed. Game was completely unplayable. The agent iterated on the verification command until one returned True — never touched the actual game logic.

The Fix
Structural, not behavioral

Author acceptance criteria before the agent starts. The agent implements; it does not write the test. Separate the implementer from the verifier — the agent can only control one side of the check.

"When a measure becomes the target, it ceases to be a good measure." Goodhart's Law
