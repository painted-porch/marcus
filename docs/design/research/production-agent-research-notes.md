## B. "What is still cobbled together": ranked (stack pass)

1. Cross-agent state, handoffs, task ownership (no protocol; memory vendors no concurrent-write guarantees; Managed Agents single-agent first; Shopify/Ramp built own session stores).
2. Trace continuity + cost attribution across agents (OTel unstable; context drops at handoffs; Temporal principal attribution, Solo budget reservations first answers).
3. Per-agent permissions and delegation chains (Okta 22%; authorization application-layer everywhere).
4. Verification of outcomes / silent failure ("semantic failures do not throw"; 52% evals; Outcomes graders).
5. Recovery and compensation (engines resume, don't compensate).
6. Cost cascades (15× tokens; retry cascades; uncached MCP schemas at boundaries).
7. Cross-vendor portability (Agent Builder retirement; Managed Agents Claude-only; A2A not critical mass).
8. Guardrails at handoffs + regulatory logging.

## D. What survived / what broke: evidence

- Survived: orchestrator/hub + narrow workers; assembly line with explicit artifacts; separate evaluator/grader roles. Gartner: 70% of MAS will use narrowly specialized agents by 2027. Forrester: <15% of firms activate agentic features in automation suites through 2026.
- Died: open-mesh peer chat; hierarchical manager delegation (Shopify "avoid multi-agent early"; CrewAI agency prefers sequential; Walmart consolidation).
- Studies: Google 180-config study (+80.9% parallelizable, −39–70% sequential; 17.2× vs 4.4× error amplification); MIT relay chains (arXiv 2603.26993: 90.7%→41.2%→22.5%; structured −2.8/stage vs prose −8.5); OrchestraBench (arXiv 2608.05263: tool faults recover 1.0, ambiguous delegation 0.30, latent semantic 0.0; cascade radius 0.9→4.7); MAST (arXiv 2503.13657); "From Spark to Fire" (arXiv 2603.04474); Anthropic research system (+90.2%, ~15× tokens).
- Surveys: Menlo 16% true agents, 76% bought; Camunda 73% vision gap, 11% reach production, 48% silos, 88% need cross-process orchestration; MuleSoft 12 agents/org, 50% isolated, 54% governed, 68% can't keep up with A2A/MCP; Gravitee 90% unmonitored agents, 85% no accountability, 54% incidents; Anthropic 57% multi-stage, 16% cross-functional, integration top blocker 46%; McKinsey 40% of $1B+ scaling agents, 37% EBIT impact, ~20% cost-constrained; a16z 37% run 5+ models; 88% LLM spend with 3 providers; LangChain 57% agents in production, 75%+ multi-model.
- Failure modes: Salesforce "echoing" (agents agree customer keeps shoes + restocking fee); CRMArena-Pro 58%→35% multi-turn; TheAgentCompany 30.3% full completion; SaaStr 20-agent incidents; Uber AI budget gone by April; HITL: 35-study review, agreement with wrong AI recommendations most consistent behavior; NHI 45:1; 40% of 7,973 MCP servers unauthenticated.

## E. Synthesis (deployment pass)

(a) Multi-agent demonstrably necessary: breadth-first evidence gathering; regulated decisions needing independent evaluator; long-running multi-party case work; org-partitioned agent estates; robots+agents hybrid pipelines.
Worse with multi-agent: sequential reasoning, most coding, early-stage products.
(b) Unsolved: undetected semantic errors; handoff fidelity; accountability (85% none); per-agent cost attribution; identity at scale; approval routing without rubber-stamping; multi-turn evaluation; standards churn.
(c) Neutral coordination layer must provide, by demand: durable state + typed handoff contracts + trusted-state signal; per-action audit attributable to a human sponsor; policy-based approval routing; per-agent/task budgets + circuit breakers; agent identity + least privilege; registry/protocol adapters surviving vendor churn; evaluator hooks.
